Crear / Actualizar parámetro en múltiples regiones

Un solo valor, varias regiones. "Ver comandos" genera el aws ssm put-parameter por región (sin tocar nada); "Crear en las regiones" lo ejecuta contra cada región seleccionada con tus credenciales y solo tras tu confirmación. Si el parámetro ya existe, se actualiza (overwrite).
